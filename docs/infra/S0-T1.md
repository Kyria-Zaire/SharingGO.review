# S0-T1 — Infrastructure dev locale

## Lancer

```bash
cp .env.example .env   # si absent
docker compose -f docker-compose.dev.yml up --build
```

## Vérifications

```bash
curl http://localhost:3000/health
# {"status":"ok"}

docker exec -it sharinggo-postgres-dev pg_isready -U postgres
```

## Structure

- `backend/` — Express, Prisma init, `/health`
- `frontend/` — Vite, React, Tailwind (noir/vert)
- `docker/` — nginx config référence
- `docker-compose.dev.yml` — postgres + backend + frontend
