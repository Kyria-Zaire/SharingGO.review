## 1. Résumé exécutif

Dernier maillon opérationnel du MVP V1 validé de bout en bout :

```text
QR passager (JWT)
→ POST /api/boarding/validate (exploitant)
→ POST /api/boarding/consume (exploitant)
→ Reservation USED + usedAt
→ Passager voit billet utilisé
→ Second consume → BOARDING_ALREADY_USED
```

**Conclusion :** le contrat boarding backend est conforme au CDC (fenêtre départ + 10 min, anti double-scan, pas de mutation sur validate seul).

## 5. Requêtes exécutées

### 5.1 Auth

```http
POST /api/auth/login
{ "email": "admin@sharinggo.demo", "password": "DemoPassword123!" }
→ 200 + cookie session admin

POST /api/auth/login
{ "email": "passenger05@sharinggo.demo", ... }
→ 200 + cookie session passager
```

### 5.2 JWT boarding

```http
GET /api/boarding/cmqj9lu8j00erlh5is3y8pymp/token
Cookie: session passager
→ 200
```

Réponse (JWT tronqué) :

```json
{
  "reservationId": "cmqj9lu8j00erlh5is3y8pymp",
  "tripId": "cmqj9ltrb003llh5i5k6ihua5",
  "boardingToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.…",
  "expiresAt": "2026-06-23T19:10:00.000Z"
}
```

### 5.3 Validate

```http
POST /api/boarding/validate
Cookie: session admin
Body: { "boardingToken": "<JWT>" }
→ 200
```

```json
{
  "valid": true,
  "reservation": { "id": "cmqj9lu8j00erlh5is3y8pymp", "status": "CONFIRMED" },
  "trip": { "departureTime": "2026-06-23T19:00:00.000Z", "line": { … } },
  "passenger": { "firstName": "Passager", "lastName": "5" }
}
```

### 5.4 Consume

```http
POST /api/boarding/consume
Cookie: session admin
Body: { "boardingToken": "<JWT>" }
→ 200
```

```json
{
  "valid": true,
  "consumed": true,
  "ui": {
    "status": "success",
    "title": "Billet valide",
    "message": "Passager embarqué"
  },
  "reservation": {
    "id": "cmqj9lu8j00erlh5is3y8pymp",
    "status": "USED",
    "usedAt": "2026-06-19T09:51:35.568Z"
  }
}
```

### 5.5 Second consume (anti double-scan)

```http
POST /api/boarding/consume
(même JWT)
→ 200
```

```json
{
  "valid": true,
  "consumed": false,
  "reason": "BOARDING_ALREADY_USED",
  "ui": {
    "status": "warning",
    "title": "Billet déjà utilisé",
    "message": "Ce billet a déjà été scanné"
  }
}
```
